# Example output shape

Each wallet directory contains `summary.md`, `summary.json`, `all_fills.csv`, same-price cumulative groups, four separate side/outcome distributions, the price-time-cumulative-shares table, event temperature structures, city summaries, market discovery, data quality, and a source manifest.

The root contains `trader_comparison.csv`, `trader_comparison.md`, and `run_manifest.json`. Conclusions use `OBSERVED`, `INFERRED`, `NOT_SUPPORTED`, or `UNKNOWN`. Public fills are not original orders, and the report contains no PnL, ROI, win rate, account operation, signing, or real order.
